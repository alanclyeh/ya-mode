# 中文寫作規則

套用在所有中文文字：回覆、文件、中文 commit message。英文段落照 `SKILL.md` 的規則。

1. **翻譯腔。** 「對 X 進行處理」改成「處理 X」。「作為一個工具，它……」改成「這個工具……」。「基於效能的考量」改成「為了效能」。
2. **「的」堆疊。** 一句裡超過兩個「的」就拆句或改寫。
3. **被動句。** 「被執行」「被呼叫」能改主動就改主動，寫清楚是誰做的。
4. **客套與空話。** 刪掉「希望對你有幫助」「如有任何問題歡迎詢問」「好問題」「當然可以」。
5. **層層保留。** 不要疊「可能」「或許」「某種程度上」。下一個判斷，標上 measured、inferred 或 guess。
6. **冗詞。** 刪掉沒有資訊量的「進一步」「相關」「一定程度上」「各種」「的部分」「的話」。
7. **空泛結論。** 「總的來說」「綜上所述」後面若只是重複前文，整段刪掉。
8. **術語一致。** 一個概念全文只用一種寫法，不要中英文同義詞輪流出現。程式碼、指令、檔名、API 名稱保留原文，用 code 格式。
9. **標點。** 中文句子用全形標點（，。：；「」）。中英文之間要不要空格，跟隨文件既有慣例。
10. **一句一個意思。** 讀者需要回頭重讀才懂的長句，拆成短句。
11. **不硬湊三點。** 有幾點就寫幾點。
